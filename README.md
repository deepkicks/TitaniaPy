# TitaniaPy
A Python CLI tool that parses, analyzes, and partially decrypts PS5 update (PUP) and BLS container files directly on PC—no console required. Features BLS metadata extraction, Layer 3 component decryption, PBKDF2/KMB derivation, and entropy-based key brute-forcing. Built as a modular framework ready for full PUP container decryption.
